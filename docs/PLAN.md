# 3일 개발 계획

기준일: 2026-10-23 · 총 12시간 · 개인 시연용

## 1일차 — 기본 도안과 계산 검사

- [ ] 색상·귀 모양·꼬리 유무를 직접 선택하는 화면
- [ ] 머리·몸통·귀·팔다리·꼬리의 직접 설계한 기본 데이터
- [ ] 각 단의 이전 코 소비량과 결과 코 수 검사
- [ ] 검사 실패 시 정상 도안 출력 차단과 오류 안내
- [ ] 선택된 특징이 반영된 부위별 결과
- [ ] 모든 결과에 실제 뜨기 검증 전 초안 표시

완료 기준: 이미지 없이 선택 항목으로 도안을 생성하고 코 수 검사를 통과한다. 잘못된 코 수 데이터를 넣으면 검사에 실패한다.

## 2일차 — 이미지 입력과 특징 수정

- [ ] 이미지 분석 서비스·비용·이미지 처리 방침 결정
- [ ] 이미지 한 장 업로드와 미리보기
- [ ] 파일 형식·용량 제한 결정과 오류 안내
- [ ] 주요 색상·귀 모양·꼬리 유무 분석
- [ ] 분석 결과를 사용자가 수정한 뒤 생성
- [ ] 분석 실패·미지원 입력 시 수동 선택으로 계속 진행

완료 기준: 이미지를 업로드하고 수정한 특징으로 도안을 생성한다.

## 3일차 — 저장과 전체 흐름 점검

- [ ] 준비물·용어·솜 넣기·마감·부착 위치·조립 순서
- [ ] 인쇄 화면과 PDF 저장
- [ ] 샘플 이미지 3~5장으로 전체 흐름 점검
- [ ] 분석 실패 및 계산 실패 흐름 확인
- [ ] 사용 방법과 확인한 한계 기록

완료 기준: 업로드부터 PDF 저장까지 시연한다. 실제 제작 검증 여부를 계산 검사와 구분해 표시한다.

## 후속 작업

숙련자에게 기본 도안의 실제 제작 검증을 받은 뒤 수정한다. 토끼형과 크기 조절은 첫 버전 완료 후 검토한다.
