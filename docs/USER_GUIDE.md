# 한 코씩 사용 안내

단순한 캐릭터 이미지를 둥근 머리·몸통과 작은 팔다리가 있는 코바늘 인형의 초안 도안으로 바꾸는 개인 시연용 도구입니다. 실제 뜨기 검증은 아직 진행하지 않았습니다.

## 도안 만들기

1. 정면 칸에 얼굴과 몸이 보이는 이미지 한 장을 넣습니다. 정면은 필수입니다.
2. 같은 캐릭터의 뒷모습이 있으면 뒷면 칸에 넣습니다. 뒷면은 없어도 됩니다.
3. 「이미지 분석하고 도안 만들기」를 누릅니다.
4. 귀 모양, 부위별 실 기호, 머리 배색과 꼬리가 참고 이미지에 맞는지 확인합니다.
5. 「인쇄 · PDF 저장」에서 PDF로 저장합니다. 새로고침하면 이미지와 결과가 사라집니다.

이미지는 각 칸에 PNG·JPG·WebP 한 장, 한 장당 최대 10MB까지 넣을 수 있습니다.

## 꼬리와 귀

- 뒷면 이미지가 없으면 정면에 꼬리가 보여도 꼬리를 만들지 않습니다.
- 뒷면이 있어도 꼬리를 확실히 확인하지 못하면 생략 사실을 표시합니다.
- 귀는 이미지에 따라 뾰족한 귀·둥근 귀·긴 귀·귀 없음으로 구성합니다.
- 긴 귀는 9단짜리 기본 구조입니다. 원본과 같은 정확한 길이나 비율을 보장하지 않습니다.

## 실 색상 읽기

색상은 원형 견본과 A/B/C 등의 기호로만 표시합니다. 같은 기호는 같은 실입니다. 색상표의 사용 부위와 각 단의 기호를 함께 보세요. 얼굴 자수용 실은 별도로 준비합니다.

머리의 배색 경계는 단순한 덮개 또는 이마 중앙이 올라오는 계단형 배색으로 표현합니다. 사진 속 모든 무늬를 그대로 재현하지는 않습니다.

## 오류가 보이면

- 앞뒤가 다르거나 서로 다른 캐릭터라고 안내하면 해당 칸의 이미지를 확인합니다. 뒷면이 없으면 뒷면 칸을 비우면 됩니다.
- 무료 한도·서비스 혼잡 안내가 나오면 반복 클릭하지 않고 나중에 다시 시도합니다. 결제 설정을 바꿀 필요는 없습니다.
- 이미지와 다른 귀·색상·꼬리가 나오면 그 결과를 검증된 도안으로 사용하지 말고, 잘못된 부위를 기록해 수정합니다.
- 자동 코 수 검사에 실패한 도안은 표시하지 않습니다. 이 검사는 실제 완성 형태를 확인하는 검증과 다릅니다.

## 이미지와 저장

분석 버튼을 누르면 축소된 이미지가 Google Gemini로 전송됩니다. 무료 구간에서는 이미지와 응답이 Google 서비스 개선에 사용될 수 있습니다. 이 사이트는 이미지 파일을 서버 디스크에 저장하지 않습니다.

현재 사이트는 개발 컴퓨터에서 실행합니다. GitHub에 코드를 올리는 것과 다른 사람이 접속할 수 있는 사이트로 배포하는 것은 별도 작업입니다. 다른 컴퓨터에서 실행하는 방법은 [프로젝트 소개](../README.md)를 참고하세요.
