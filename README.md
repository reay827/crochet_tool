# 이미지 기반 코바늘 인형 도안 생성 도구

이미지의 색상과 특징을 반영해 단순한 고양이형 코바늘 인형의 **초안 도안**을 만드는 개인 시연용 프로젝트입니다.

> 모든 도안은 실제 뜨기 검증 전 초안입니다. 코 수 계산 검사 통과가 완성 형태와 조립의 적절함을 보장하지는 않습니다.

## 현재 상태

첫 로컬 시연 버전 구현. 이미지 미리보기, 수동 특징 선택, 기본 도안 생성, 코 수 검사, 인쇄를 사용할 수 있습니다. 자동 이미지 분석은 아직 연결하지 않았습니다. 업로드한 이미지는 분석되지 않으며 선택 항목의 기본값에도 영향을 주지 않습니다.

## 실행 방법

설치 없이 `index.html`을 브라우저에서 열면 사용할 수 있습니다. 이미지는 브라우저 메모리에서만 표시되며 외부 전송·영구 저장하지 않습니다. 새로고침하면 선택한 이미지와 결과는 사라집니다. 필요한 도안은 인쇄 버튼에서 PDF로 저장하세요.

Node.js가 있는 개발 환경에서는 `node serve.cjs` 실행 후 `http://127.0.0.1:4173`에 접속할 수 있습니다. 종료는 실행 중인 터미널에서 Ctrl+C를 누릅니다.

## 첫 사용 확인

1. PNG·JPG·WebP 이미지 한 장(10MB 이하)을 선택합니다.
2. 사진을 보며 몸 색상, 귀·꼬리 색상, 귀 모양, 꼬리 유무를 직접 정합니다.
3. 초안 도안 만들기를 눌러 검사 결과와 부위별 표를 확인합니다.
4. 특징을 변경하면 이전 결과가 숨겨집니다. 다시 생성해 반영을 확인합니다.
5. 인쇄 · PDF 저장을 누르고 인쇄 대상을 PDF로 선택합니다.

현재 머리·몸통은 분리형이며, 머리 위 색상 무늬는 지원하지 않습니다. 정면·뒷면을 동시에 올리는 기능은 아직 없습니다. 이미지 없이도 도안 생성이 가능합니다.

## 확정한 범위

- 사진의 특징을 반영한 귀여운 단순 인형
- 고양이형 하나, 직접 설계한 기본 도안
- 주요 색상, 지원되는 귀 모양, 꼬리 유무 선택과 수정
- 구조화된 도안 데이터에 기반한 단별 코 수 검사
- 부위별 제작법, 준비물, 용어, 조립 안내
- 인쇄 및 브라우저의 PDF 저장
- 우선 개인 시연용으로 개발

이미지 분석 서비스, 비용, 이미지 처리 방침은 연결 전에 결정합니다. 임의의 이미지를 그대로 재현하거나 정확한 완성 크기·실 소요량을 보장하지 않습니다.

## 진행 순서

1. 이미지 없이 특징을 직접 선택해 도안을 생성하고 검사합니다.
2. 이미지 업로드·분석을 연결하고 사용자가 특징을 수정하게 합니다.
3. 인쇄·저장과 오류 안내를 완성하고 샘플 3~5장으로 확인합니다.

자세한 완료 기준은 [개발 계획](docs/PLAN.md)을 참고하세요.

## GitHub를 처음 사용할 때

- **저장소(Repository)**: 프로젝트 파일과 변경 기록을 보관하는 공간입니다.
- **커밋(Commit)**: 변경 내용을 설명과 함께 기록하는 저장 지점입니다.
- **푸시(Push)**: 컴퓨터의 기록을 GitHub로 올리는 작업입니다.
- **이슈(Issue)**: 할 일이나 발견한 문제를 적는 메모입니다.

초기에는 기본 브랜치 하나에서 작은 기능을 완성할 때마다 기록합니다. 변경 전후 동작을 확인하고, 무엇을 바꿨는지 짧게 적습니다.

## 파일과 개인정보

API 키·비밀번호는 저장소에 올리지 않습니다. 실제 키는 `.env` 같은 로컬 설정 파일에 보관하고, 브라우저에 전달되는 코드에도 넣지 않습니다. `.gitignore`는 실수 방지를 돕지만 모든 비밀정보를 자동으로 찾아주지는 않습니다.

개인 사진과 사용 권한이 불명확한 이미지·도안은 올리지 않습니다. 아직 공개 라이선스를 선택하지 않았습니다.

## 검증

`node test-pattern.cjs`로 귀·꼬리 4개 조합, 잘못된 결과 코 수, 이전 단 코 소비량 오류, 잘못된 입력의 검사를 실행합니다. 브라우저에서는 업로드 오류, 선택 변경, 결과 생성과 인쇄를 확인합니다. 계산 검사와 숙련자의 실제 제작 검증은 별개이며, 실제 제작 검증은 아직 진행하지 않았습니다.
