# 이미지 기반 코바늘 인형 도안 생성 도구

이미지의 색상과 특징을 반영해 단순한 고양이형 코바늘 인형의 **초안 도안**을 만드는 개인 시연용 프로젝트입니다.

> 모든 도안은 실제 뜨기 검증 전 초안입니다. 코 수 계산 검사 통과가 완성 형태와 조립의 적절함을 보장하지는 않습니다.

## 현재 상태

이미지 업로드 → AI 자동 분석 → 코 수 검사 → 도안 생성 흐름을 구현했습니다. 수동 특징 선택은 제거했습니다. 로컬 환경에 무료 프로젝트 설정을 연결했습니다. 저장소에는 비밀키를 포함하지 않으므로 다른 컴퓨터에서 실행할 때는 별도 설정이 필요합니다. 실제 연결 점검은 [확인 기록](docs/VERIFICATION.md)을 참고하세요.

## 실행 방법

자동 분석에는 로컬 서버가 필요합니다. `index.html`을 파일로 직접 열면 분석 기능은 작동하지 않습니다. 새로고침하면 이미지와 결과는 사라집니다. 필요한 도안은 인쇄 버튼에서 PDF로 저장하세요.

Node.js가 있는 개발 환경에서는 `node serve.cjs` 실행 후 `http://127.0.0.1:4173`에 접속할 수 있습니다. 종료는 실행 중인 터미널에서 Ctrl+C를 누릅니다.

## 첫 사용 확인

1. 같은 캐릭터의 PNG·JPG·WebP 이미지 1~2장(한 장당 10MB 이하)을 선택합니다.
2. 정면과 뒷면을 함께 선택하면 꼬리 확인에 도움이 됩니다.
3. 연결 준비 완료 후 「이미지 분석하고 도안 만들기」를 누릅니다.
4. AI 분석 결과와 자동 코 수 검사 결과, 부위별 표를 확인합니다. 이미지가 바뀌면 이전 결과는 숨겨집니다.
5. 인쇄 · PDF 저장을 누르고 인쇄 대상을 PDF로 선택합니다.

현재 머리·몸통은 분리형입니다. 넓은 머리 위 색상 영역과 이마 중앙의 배색 홈을 자동으로 읽습니다. 중앙 홈이 있으면 1~3단은 머리 위 색, 4단은 머리 위 색 10코→몸 색 4코→머리 위 색 10코, 5단은 각 색 10코씩, 6~17단은 몸 색입니다. 각 색 구간의 뜨기 지시와 실 전환 방법을 표에 표시합니다. 단 시작은 뒤 중심이고 몸 색 구간 중앙이 얼굴 정면입니다. 홈이 없는 배색은 1~5단 머리 위 색의 둥근 덮개로 단순화합니다. 색상 구간의 코 수·뜨기 순서도 검사하지만 실제 제작 검증은 아직 없습니다. 원본의 곡선은 계단형 배색으로 근사합니다. 꼬리 확인 불가나 미지원 형태는 결과 또는 오류에 안내합니다.

## 무료 이미지 분석 연결

Google AI Studio에서 결제가 연결되지 않은 Free Tier 프로젝트를 사용합니다. 계정별 무료 사용 가능 여부와 한도는 다를 수 있습니다. 무료 사용이 불가능하면 결제를 연결하지 말고 작업을 멈춥니다.

1. 사용자가 Google AI Studio에서 무료 프로젝트를 확인하고 API 키를 발급합니다.
2. `.env.example`을 `.env`로 복사한 뒤 키를 로컬 `.env`에만 입력합니다. 채팅이나 GitHub에 키를 보내지 않습니다.
3. 프로젝트가 결제 미연결·Free Tier임을 직접 확인한 후에만 `GEMINI_FREE_TIER_CONFIRMED=yes`로 변경합니다. 이 설정은 사용자 확인 표시이며 서비스의 결제 상태를 자동 조회하는 기능은 아닙니다.
4. 로컬 서버를 다시 시작합니다. 준비되지 않은 상태에서는 분석 요청을 차단합니다.

기본 모델은 무료 입력·출력 구간이 문서에 명시된 `gemini-3.5-flash-lite`이며 Interactions API를 사용합니다. 상호작용 저장은 `store:false`로 요청합니다. 무료 한도 초과나 서비스 혼잡 시 오류를 안내하며 다른 모델로 자동 전환하거나 자동 재시도하지 않습니다. 로컬 서버 실행당 최대 10회 분석 요청으로 제한합니다. 이 횟수 제한은 과금 방지를 보장하지 않으므로 반드시 결제 미연결 무료 프로젝트를 사용해야 합니다.

분석 버튼을 누르면 브라우저에서 긴 변 1536px 이하의 JPEG로 변환한 이미지가 Google로 전송됩니다. 사이트는 이미지를 디스크에 보관하지 않습니다. Google 무료 구간에서는 입력 이미지와 출력이 서비스 개선에 사용될 수 있습니다.

공식 문서: [무료 구간·데이터 사용](https://ai.google.dev/gemini-api/docs/pricing), [결제와 무료 프로젝트](https://ai.google.dev/gemini-api/docs/billing).

## 확정한 범위

- 사진의 특징을 반영한 귀여운 단순 인형
- 고양이형 하나, 직접 설계한 기본 도안
- 주요 색상, 지원되는 귀 모양, 꼬리 유무 자동 추출 (사용자 요청으로 수동 선택 제외)
- 구조화된 도안 데이터에 기반한 단별 코 수 검사
- 부위별 제작법, 준비물, 용어, 조립 안내
- 인쇄 및 브라우저의 PDF 저장
- 우선 개인 시연용으로 개발

유료 서비스는 사용하지 않습니다. Gemini 무료 프로젝트 연결은 사용자와 확인 후 진행합니다. 임의의 이미지를 그대로 재현하거나 정확한 완성 크기·실 소요량을 보장하지 않습니다.

## 진행 순서

1. 구조화된 기본 도안과 자동 코 수 검사를 준비합니다. (완료)
2. 수동 선택 없이 업로드한 이미지를 자동 분석하도록 연결합니다. (코드 준비, 무료 계정 연결 대기)
3. 인쇄·저장과 오류 안내를 완성하고 샘플 3~5장으로 확인합니다.

자세한 완료 기준은 [개발 계획](docs/PLAN.md)을 참고하세요.

## GitHub를 처음 사용할 때

- **저장소(Repository)**: 프로젝트 파일과 변경 기록을 보관하는 공간입니다.
- **커밋(Commit)**: 변경 내용을 설명과 함께 기록하는 저장 지점입니다.
- **푸시(Push)**: 컴퓨터의 기록을 GitHub로 올리는 작업입니다.
- **이슈(Issue)**: 할 일이나 발견한 문제를 적는 메모입니다.

초기에는 기본 브랜치 하나에서 작은 기능을 완성할 때마다 기록합니다. 변경 전후 동작을 확인하고, 무엇을 바꿨는지 짧게 적습니다.

## 파일과 개인정보

API 키·비밀번호는 저장소에 올리지 않습니다. 실제 키는 `.env` 같은 로컬 설정 파일에 보관하고, 브라우저에 전달되는 코드에도 넣지 않습니다. `.gitignore`는 실수 방지를 돕지만 모든 비밀정보를 자동으로 찾아주지는 않습니다.

개인 사진과 사용 권한이 불명확한 이미지·도안은 올리지 않습니다. 아직 공개 라이선스를 선택하지 않았습니다.

## 검증

실 색상은 부위별 명칭 대신 A·흰색, B·하늘색처럼 도안 전체에서 같은 기호와 색상명을 사용합니다. RGB 값이 아주 가까운 색(거리 32 이하)은 먼저 등장한 실 색으로 묶고, 충분히 다른 색은 유지합니다. 예를 들어 머리 위와 귀의 파랑이 약간 달라도 같은 실로 안내합니다. 원본의 미세한 색 차이를 보존해야 하는 도안에는 이 단순화의 한계가 있습니다.

색상 견본은 CSS 배경 대신 SVG 전경 도형으로 출력하고, 인쇄 색 보존 설정을 적용합니다. 배경 그래픽을 끈 인쇄에서도 도형 자체가 출력되도록 변경했습니다. 실제 PDF 파일의 출력 결과는 별도 확인이 필요합니다. 흑백 출력에서도 A/B 기호와 색상명이 남습니다.

`node test-palette.cjs`로 같은 색의 대소문자·미세한 색 차이 묶기, 일관된 실 이름, 충분히 다른 색 유지 동작을 검사합니다.

`node test-pattern.cjs`와 `node test-analysis.cjs`를 실행합니다. 후자는 가짜 분석 응답을 이용한 연결·예외 처리 검사이며 외부 API를 호출하지 않습니다. 실제 이미지 분석 품질은 키 연결 후 별도로 검증해야 합니다. 계산 검사와 숙련자의 실제 제작 검증은 별개이며, 실제 제작 검증은 아직 진행하지 않았습니다.
